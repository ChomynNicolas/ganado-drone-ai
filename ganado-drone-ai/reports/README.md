# Resultados e informe

Este directorio contendrá tablas, figuras de errores y fuentes del informe
IEEE. Los resultados deben provenir de evaluaciones reproducibles.

Métricas planificadas: mAP@0.5, mAP@0.5:0.95, precisión, recall,
MAE de conteo **por imagen** y latencia de inferencia identificando hardware.
No se cargan cifras hasta realizar experimentos reales.

Los resultados generados automáticamente se guardarán en `reports/generated/`
(ignorado por Git). Seleccionar para versionado solo resúmenes finales
pequeños, verificables y sin datos de terceros no autorizados.
