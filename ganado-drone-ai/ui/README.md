# Interfaz de usuario (pendiente)

El dashboard se construirá con Streamlit, **sin implementación aún**.
Su responsabilidad será enviar imágenes a la API, dibujar las cajas a partir de
coordenadas devueltas y mostrar el conteo por fotografía.

## Regla de conteo

La suma de detecciones por fotografía **no** equivale a ganado único si hay
imágenes superpuestas. La interfaz deberá dejar visible esta limitación.
